# UPI Mesh Frontend

A React-based frontend for the UPI Offline Mesh payment system.

## Features

- Dashboard for UPI accounts
- Send money through the mesh network
- Transaction history
- Mesh network status
- Backend connection status
- Mesh gossip and flush controls
- Responsive UI

## Tech Stack

- React
- Vite
- JavaScript
- Lucide React
- CSS
- Spring Boot REST API

## Backend

This frontend connects to the Spring Boot backend running on:
https://upi-without-internet-fyww.onrender.com
